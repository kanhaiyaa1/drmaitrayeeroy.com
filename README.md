# drmaitrayeeroy.com

Single-page portfolio for Prof. (Dr.) Maitrayee Roy. Next.js (App Router), TypeScript and Tailwind CSS v4, built as a static export.

```bash
npm run dev     # local development
npm run build   # static export
```

Before launch: set the Web3Forms access key in `components/EnquiryForm.tsx` and resolve the `TODO` comments across the project.
